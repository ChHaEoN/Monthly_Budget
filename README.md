# Monthly Budget｜每月開銷

個人用的記帳網頁：匯入 **DKB**、**VISA Amazon**、**AMEX** 的每月帳單 (CSV)，自動分類並計算每個月的**實際開銷**。

純靜態網頁，沒有後端。所有資料只存在瀏覽器的 `localStorage`，不會上傳到任何地方。

## 使用方式

```bash
npm start
```

然後開啟 <http://localhost:8000>。（因為使用 ES modules，不能直接雙擊 `index.html` 開啟；也可以部署到任何靜態主機。）

1. 從各家網銀匯出 CSV，拖進頁面。
2. 匯入預覽會自動辨識來源、欄位與正負號，確認後匯入。
3. 在「總覽」查看當月實際開銷、分類佔比與近 12 個月趨勢。
4. 在「交易明細」修正分類，並可順手存成規則，之後自動套用。

## 「實際開銷」怎麼算

- 支出類交易的淨額；退款（正數）會抵減開銷。
- **信用卡繳款不重複計算**：DKB 扣繳 AMEX / Amazon Visa 帳單、以及信用卡端收到的繳款，都歸入「內部轉帳（不計入）」，消費只在信用卡明細中算一次。
- 儲蓄投資（如 Trade Republic、Sparplan）不計入開銷。
- 月份以交易日期歸屬（信用卡優先採用消費日而非入帳日）。
- DKB 尚未入帳 (Vorgemerkt) 的交易會略過，待入帳後再匯入。

## 其他

- **去重**：重複匯入同一份、或期間重疊的帳單不會重複計算。
- **規則**：關鍵字比對交易說明（不分大小寫、需位於單字開頭）。自訂規則優先於內建規則；手動改過的分類不會被覆蓋。
- **備份**：「匯入與備份」可匯出完整 JSON 備份，拖回頁面即可還原。清除瀏覽器資料會刪除所有紀錄，請定期備份。
- **格式不合時**：匯入預覽中可手動指定日期／金額／說明欄位與正負號。目前不支援 PDF。

## 開發

```bash
npm test
```

- `js/parse.js` CSV 解析與來源辨識
- `js/categorize.js` 分類與規則
- `js/store.js` 儲存、去重、月結計算
- `js/app.js` 介面
- `test/samples/` 虛構的範例帳單
